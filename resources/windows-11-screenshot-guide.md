# Windows 11 Screenshot Guide

Screenshots are evidence. In IT support, screenshots help show what you checked and what the computer displayed at the time.

## Method 1: Snipping Tool

1. Press `Windows + Shift + S`.
2. Select the part of the screen you need.
3. Click the screenshot notification if it appears.
4. Save the screenshot with a clear file name.

Example file name:

```text
task-manager-lastname.png
```

## Method 2: Full Screen Screenshot

1. Press `Windows + PrtScn`.
2. Windows usually saves the image in:

```text
Pictures\Screenshots
```

## Method 3: Copy Screenshot To Clipboard

1. Press `PrtScn`.
2. Open Word, Paint, or another document.
3. Press `Ctrl + V` to paste.

## Good Screenshot Habits

- Capture the important window, not your whole desktop if possible.
- Do not include private information if you can avoid it.
- Use clear names like `storage-status-lastname.png`.
- Put screenshots in a folder named `Screenshots`.
