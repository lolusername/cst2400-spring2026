# Glossary

## Active Directory

A Microsoft system used by many organizations to manage users, computers, groups, and access to resources.

## Administrator

An account with permission to make major changes to a computer. These labs are designed so students do not need administrator access.

## Command Prompt

A Windows tool for typing commands. Some networking commands, such as `ipconfig` and `ping`, can run here.

## DNS

Domain Name System. DNS turns names like `example.com` into addresses that computers can use.

## Evidence

Information that shows what you checked. In this class, evidence often means screenshots or command output.

## File Explorer

The Windows app used to browse folders, files, Desktop, Documents, Downloads, and drives.

## Firewall

A security tool that controls allowed network traffic.

## Group

A collection of user accounts. In IT support, permissions are often assigned to groups instead of one person at a time.

## Help Desk

The first support team users contact when they have computer, account, software, or access problems.

## IP Address

A number that identifies a device on a network.

## MFA

Multi-factor authentication. A login method that requires more than just a password.

## PowerShell

A Microsoft command-line tool used for automation and system information. In this class, PowerShell is used only for safe evidence gathering.

## Recycle Bin

The Windows location where many deleted files go before they are permanently removed.

## Task Manager

A Windows tool that shows running apps, processes, performance, and startup apps.

## Troubleshooting

A step-by-step process for identifying a problem, checking evidence, and choosing the safest next step.
