# Windows 11 Keyboard Shortcuts

These shortcuts are useful for Windows 11 class labs and entry-level IT support.

| Shortcut | What It Does |
| --- | --- |
| `Windows` | Opens Start |
| `Windows + E` | Opens File Explorer |
| `Windows + I` | Opens Settings |
| `Windows + S` | Opens Search |
| `Windows + X` | Opens the power user menu |
| `Windows + Shift + S` | Opens screenshot snipping |
| `Ctrl + C` | Copy |
| `Ctrl + V` | Paste |
| `Ctrl + X` | Cut |
| `Ctrl + Z` | Undo |
| `Alt + Tab` | Switch between open apps |
| `Ctrl + Shift + Esc` | Open Task Manager |

## Support Tip

If you forget where something is, use Search first. A good technician does not know every path by memory; a good technician knows how to find tools safely.
