# Course Schedule

This two-week boot camp is beginner-friendly and job-facing. Each class includes a short lecture, a live demonstration, and a hands-on lab.

## Grading Update

The final exam grade will be recorded as **100% for everyone**.

Because the course schedule has changed, the remaining meetings will focus on practical Windows 11 IT support skills instead of a traditional high-pressure final exam. Labs are optional in-class skill-building activities. Your instructor may ask you to submit screenshots or a short write-up in Brightspace to document participation and practice, but these labs are not a new high-stakes grading burden.

## Week 1

| Class | Topic | Main Skills | Student Deliverable |
| --- | --- | --- | --- |
| Class 1 | Windows 11 Desktop and Troubleshooting | Start menu, taskbar, search, screenshots, Task Manager, Settings, ticket writing | Screenshots plus a short support note |
| Class 2 | Files, Search, Recovery, and Security | File Explorer, Recycle Bin, Windows Search, Windows Security, suspicious-file judgment | Screenshots plus a short file/security response |

## Week 2

| Class | Topic | Main Skills | Student Deliverable |
| --- | --- | --- | --- |
| Class 3 | Networking and Identity Basics | IP address, DNS, `ipconfig`, `ping`, `tracert`, user accounts, groups, MFA | Network evidence plus onboarding/access table |
| Class 4 | PowerShell and Help Desk Simulation | Safe PowerShell commands, evidence gathering, final support report | Screenshots plus a three-ticket support report |

## What To Submit

Your instructor will tell you what to submit in Brightspace. Most labs ask for:

- 3 to 5 screenshots
- A short written response
- A completed checklist or table

## Professional Habits

For each lab, practice these habits:

- Name files clearly.
- Save work where you can find it.
- Take screenshots as evidence.
- Write in clear, respectful support language.
- Do not guess when you can check.
