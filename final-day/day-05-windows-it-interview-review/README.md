# Day 5: Windows IT Skills Interview Review

## Goal

Review the Windows 11 IT support skills from the boot camp and turn them into interview answers, resume bullets, and clear examples you can talk about.

## Today You Will Practice

- Collecting safe Windows evidence
- Explaining troubleshooting steps in plain English
- Turning class labs into interview stories
- Writing beginner help-desk resume bullets
- Answering common entry-level IT interview questions
- Practicing professional support communication

## Why This Matters

Entry-level IT interviews usually do not expect you to know everything. They do expect you to explain how you think, how you stay safe, how you document evidence, and how you communicate with users.

Today is a review lab, but it is also interview preparation.
