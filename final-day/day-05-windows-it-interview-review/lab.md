# Lab: Windows IT Interview Skills Challenge

**Submit in:** Brightspace, if instructed  
**Estimated time:** 75 to 100 minutes  
**Difficulty:** Easy review with useful career practice  
**Theme:** Build a mini interview portfolio from your Windows 11 IT support skills

## Scenario

You are applying for a beginner IT support job. The interviewer asks:

```text
Can you give examples of Windows troubleshooting skills you have practiced?
```

Your job today is to collect simple evidence, write interview-ready answers, and leave with examples you can use in a real conversation.

## Part 1: Create Your Skill Portfolio Folder

On the Desktop, create this folder:

```text
Day5_IT_Interview_LastName
```

Inside it, create:

```text
Screenshots
Interview_Answers
Resume_Bullets
Ticket_Practice
```

Take a screenshot of the folder structure.

## Part 2: Windows Evidence Scavenger Hunt

Choose **four** of the following evidence tasks. Take one screenshot for each task you complete.

Do not change settings. Just inspect and document.

| Choice | Evidence Task | What It Helps You Explain In An Interview |
| --- | --- | --- |
| A | Open Task Manager and view running apps or performance | How you begin checking a slow computer |
| B | Open Settings > System > Storage | How you check disk space and storage problems |
| C | Open Windows Security and view protection areas | How you think about safe security checks |
| D | Open Network & internet settings | How you collect first evidence for a network issue |
| E | Run `ipconfig` in Command Prompt or PowerShell | How you gather network information |
| F | Run `Get-Date` and `Get-Process` in PowerShell | How you use safe read-only commands |
| G | Open File Explorer, right-click a file, and view Properties | How you check file location, type, size, and dates |
| H | Use Windows Search to find a file or app | How you help users locate things quickly |

Put the screenshots in your `Screenshots` folder.

## Part 4: Ticket Speed Round

Choose **two** tickets. For each ticket, write a short support response with:

1. What the user reported.
2. What you would check first.
3. What screenshot or evidence you would collect.
4. A safe next step.
5. A user-friendly explanation.

### Ticket Options

```text
Ticket A: My laptop is very slow today.
Ticket B: I cannot find the file I saved yesterday.
Ticket C: My internet says connected, but websites do not load.
Ticket D: I received an email attachment that looks suspicious.
Ticket E: A new employee needs access to the help desk system and staff printer.
```

## Part 5: Resume Bullet Builder

Create **three** resume bullets using skills from this boot camp.

Use action verbs like:

```text
Troubleshot
Documented
Collected
Analyzed
Explained
Used
Practiced
Verified
```

Example:

```text
- Practiced beginner Windows 11 troubleshooting by collecting screenshots, checking system tools, and writing clear support-ticket notes.
```

Write your three bullets in the same document as Part 3.

## Part 6: Interview Question Practice

Answer **three** of these interview questions in 3 to 5 sentences each.

```text
1. What would you do first if a user says their computer is slow?
2. How would you help a user who lost a file?
3. What would you do if a user reports a suspicious email attachment?
4. What command or Windows tool have you practiced, and what does it show?
5. What would you do if you do not know the answer to a technical problem?
6. Why is documentation important in IT support?
```

Use this structure:

```text
First, I would...
Then, I would collect evidence by...
I would avoid...
I would explain to the user that...
```

## Part 7: Optional Pair Practice

If your instructor allows, pair up with another student.

1. Ask your partner one interview question from Part 6.
2. Listen for a clear process, not a perfect answer.
3. Give one helpful suggestion.

Good feedback sounds like:

```text
Your answer was clear. Add one specific Windows tool you would use.
```
