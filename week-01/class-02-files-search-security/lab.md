# Lab: Lost File, Search Evidence, and Suspicious Download

**Points:** 20  
**Submit in:** Brightspace, if instructed  
**Estimated time:** 75 to 90 minutes

## Scenario

A user says:

```text
I lost my assignment, and I also downloaded something that might be suspicious.
```

Your job is to gather evidence, recover a practice file, use search instead of guessing, inspect file details, and write safe security advice.

## How This Lab Works

Your instructor will do a short launch demo only. Most of class is lab time. Work through the steps independently or with a partner, but submit your own screenshots and writing.

## Part 1: Create Your Work Folder

On the Desktop, create this folder:

```text
Class2_LastName
```

Inside it, create:

```text
Evidence
Recovered_File
Notes
Security_Check
Writeup
```

Open the folder in File Explorer. Change the view to `Details` if you can:

```text
View > Details
```

Take a screenshot of the folder structure.

## Part 2: Create A Practice Assignment And Inspect It

Open Notepad and type:

```text
Lost Assignment Practice
Today I practiced finding and recovering files in Windows 11.
This file is safe because I created it myself during class.
```

Save the file as:

```text
lost_assignment_LastName.txt
```

Save it inside the `Notes` folder.

Right-click the file and open `Properties`.

| Opens with | |
| Location | |

| Date modified | |

Take a screenshot of the file Properties window.

## Part 3: Copy, Delete, Restore, And Verify

1. Copy `lost_assignment_LastName.txt`.
2. Paste the copy into `Recovered_File`.
3. Delete the copy from `Recovered_File`.
4. Open Recycle Bin.
5. Restore the deleted copy.
6. Confirm the file returned to `Recovered_File`.

Take screenshots showing:

- Recycle Bin before restore, if possible
- The restored file inside `Recovered_File`
- The `Recovered_File` folder in Details view

Do not delete the original file in `Notes`.

## Part 4: Search Like IT Support

Use File Explorer search to complete at least three searches.

### Search A: Search By Name

Search:

```text
lost_assignment
```

Take a screenshot of the search result.

### Search B: Search By File Type

Search:

```text
*.txt
```

Take a screenshot of the search result.

### Search C: Search By Date Or Sort By Date

Try one of these:

```text
datemodified:today
```

or sort the folder by `Date modified`.

Take a screenshot of whichever one works on your computer.

Write two sentences:

```text
I found the file by:
The most useful search method was:
```

## Part 5: Check Windows Security

Open Windows Security.

Take screenshots of:

- Virus and threat protection
- Firewall and network protection

Do not change any settings.

## Part 6: File Safety Triage

You do not need to download anything. Read each situation and classify it as `Safe`, `Suspicious`, or `Ask IT`.

Then write one short reason for each choice.

| Scenario | Safe, Suspicious, or Ask IT | Reason |
| --- | --- | --- |
| A teacher posts a file in Brightspace for class. | | |
| An email says your account will close today unless you click a link. | | |
| A browser pop-up says your PC is infected and asks you to call a number. | | |
| A coworker sends an unexpected `.exe` file with no explanation. | | |
| You download a PDF from an official school website. | | |

## Part 7: Write Your Support Response

Create a file named:

```text
class2_support_note_LastName.docx
```

If Word is not available, use Notepad and save:

```text
class2_support_note_LastName.txt
```

Write 6 to 8 sentences using this structure:

```text
Problem:
Evidence checked:
Recovery steps:
Search results:
Security advice:
Next step:
```

Your response should explain:

1. How you recovered the file.
2. What file Properties told you.
3. Which search methods worked best.
4. What Windows Security areas you checked.
5. What a user should do before opening an unexpected file.
6. Why asking IT is better than guessing.
