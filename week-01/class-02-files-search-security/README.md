# Class 2: Files, Search, Recovery, and Security

## Goal

Practice the Windows 11 skills needed when a user loses a file or is unsure whether a download is safe.

## Today You Will Practice

- Creating folders
- Naming files clearly
- Using Details view and file properties
- Copying, deleting, and restoring a file
- Searching for files with useful search patterns
- Checking Windows Security areas
- Classifying suspicious files and messages
- Writing a user-friendly support response

## Why This Matters

Many workplace problems are file location problems or security judgment problems. Entry-level support technicians help users find files, recover simple mistakes, identify risky file behavior, and avoid unsafe clicks.

## Lab Style

Your instructor will give a short launch demo, then most of class will be independent lab time. Use the lab steps, ask questions when stuck, and take screenshots as evidence.
