# Class 2: Files, Search, Recovery, and Security

## Goal

Practice the Windows 11 skills needed when a user loses a file or is unsure whether a download is safe.

## Today You Will Practice

- Creating folders
- Naming files clearly
- Copying, deleting, and restoring a file
- Searching for files
- Checking Windows Security areas
- Writing a user-friendly file and security response

## Why This Matters

Many workplace problems are file location problems or security judgment problems. Entry-level support technicians help users find files, recover simple mistakes, and avoid unsafe clicks.
