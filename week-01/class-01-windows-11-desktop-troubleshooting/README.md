# Class 1: Windows 11 Desktop and Troubleshooting

## Goal

Practice the basic Windows 11 skills an entry-level support technician uses when a user says, "My computer is slow."

## Today You Will Practice

- Opening Start, Search, Settings, File Explorer, and Task Manager
- Checking startup apps
- Checking storage status
- Checking Windows Update status
- Taking screenshots
- Writing a short help-desk support note

## Why This Matters

Many support tickets begin with a vague problem: slow computer, missing file, no internet, or cannot log in. A technician needs to inspect the computer, collect evidence, and explain the next step clearly.
