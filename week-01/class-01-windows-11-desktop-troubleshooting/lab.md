# Lab: First Help Desk Ticket - Windows 11 Desktop Checkup

**Points:** 20  
**Submit in:** Brightspace, if instructed  
**Estimated time:** 60 to 75 minutes

## Scenario

A user says:

```text
My computer feels slow and I cannot get my schoolwork done.
```

Your job is not to "fix everything." Your job is to gather safe evidence and write a clear support note.

## Part 1: Create Your Work Folder

On the Desktop, create this folder:

```text
Class1_LastName
```

Replace `LastName` with your actual last name.

Inside it, create:

```text
Screenshots
Notes
Writeup
```

Take one screenshot showing your folder structure.

## Part 2: Check Task Manager

1. Press `Ctrl + Shift + Esc`.
2. If Task Manager opens in simple view, click `More details`.
3. Look for columns such as CPU, Memory, and Disk.
4. Take a screenshot.

Write one sentence in your notes:

```text
Task Manager showed:
```

## Part 3: Check Startup Apps

1. Open Settings with `Windows + I`.
2. Go to `Apps`.
3. Open `Startup`.
4. Take a screenshot.

Do not turn anything on or off unless your instructor says to.

Write one sentence:

```text
Startup apps showed:
```

## Part 4: Check Storage

1. Open Settings.
2. Go to `System`.
3. Open `Storage`.
4. Take a screenshot.

Write one sentence:

```text
Storage showed:
```

## Part 5: Check Windows Update

1. Open Settings.
2. Go to `Windows Update`.
3. Take a screenshot of the update status.

Do not install updates unless your instructor says to.

Write one sentence:

```text
Windows Update showed:
```

## Part 6: Use Search Like A Technician

Use Windows Search to find these tools:

- Task Manager
- Settings
- File Explorer
- Device Manager

Take one screenshot showing Search results for one of those tools.

## Part 7: Write Your Support Note

Create a file named:

```text
class1_support_note_LastName.docx
```

If Word is not available, use Notepad and save:

```text
class1_support_note_LastName.txt
```

Write 5 to 7 sentences answering:

1. What did the user report?
2. What did you check?
3. What screenshots did you collect?
4. What is one likely next step?
5. How would you explain this to the user politely?

## Required Screenshots

- [ ] Folder structure
- [ ] Task Manager

- [ ] Storage
- [ ] Windows Update
- [ ] Search result for a Windows tool
