# Class 1 Submission Checklist

Before submitting in Brightspace, make sure your folder contains:

- [ ] Screenshot of your `Class1_LastName` folder structure
- [ ] Screenshot of Task Manager
- [ ] Screenshot of Startup apps
- [ ] Screenshot of Storage
- [ ] Screenshot of Windows Update
- [ ] Screenshot of Windows Search finding a Windows tool
- [ ] Written support note named clearly

## Support Note Check

Your note should include:

- [ ] The user problem
- [ ] What you checked
- [ ] What screenshots you collected
- [ ] A safe next step
- [ ] A polite explanation for the user

## File Naming Example

```text
Class1_Rivera
  Screenshots
  Notes
  Writeup
```
