# Class 4: PowerShell and Help Desk Simulation

## Goal

Use safe commands and Windows tools to complete a mini help-desk simulation.

## Today You Will Practice

- Opening PowerShell
- Running safe read-only commands
- Saving command output as evidence
- Reviewing slow computer evidence
- Reviewing network evidence
- Reviewing account/access evidence
- Writing a professional three-ticket support report

## Why This Matters

PowerShell can look intimidating, but entry-level technicians often start with simple read-only commands that show system information. The important habit is knowing what a command does before running it.

## Safety Rules

- Only run the commands listed in the lab.
- Do not run scripts from the internet.
- Do not change execution policy.
- Do not run commands you do not understand.
- Do not run commands as administrator.
