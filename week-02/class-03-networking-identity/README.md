# Week 2 Day 1: Catch-Up + Networking and Identity Starter

## Goal

Complete the missed Week 1 Day 2 files/search/recovery/security lab, then start beginner network troubleshooting and workplace access concepts.

## Today You Will Practice

- Organizing a support evidence folder
- Checking file Properties and Details view
- Recovering a deleted practice file
- Searching by name, file type, and date
- Checking Windows Security screens
- Opening network settings
- Running safe network commands
- Reading basic `ipconfig` information
- Understanding DNS and gateway concepts
- Simulating basic user/group access
- Writing a combined support note

## Why This Matters

Entry-level IT support often starts with ordinary problems: missing files, suspicious downloads, internet issues, and access requests. You do not need to be an expert to collect useful evidence and explain the next safe step.

## Attendance Note

Because many students missed Week 1 Day 2, this class includes that file/security lab before moving into networking and identity.

If you already completed the file/security work, use the catch-up section to improve your screenshots and written support response. Then continue to the networking section.

## Safety Rules

- Do not delete personal files.
- Do not download anything for this lab.
- Do not open suspicious links or attachments.
- Only run the commands listed in the lab.
- Do not change network settings.
- Do not share private network information outside class.
- Do not change Windows Security settings.
- If a command is blocked, use the sample-output option in the lab.
