# Class 3: Networking and Identity Basics

## Goal

Practice beginner network troubleshooting and learn how workplace access is usually handled with accounts, groups, and MFA.

## Today You Will Practice

- Opening network settings
- Running safe network commands
- Reading basic `ipconfig` information
- Understanding DNS and gateway concepts
- Comparing `ping` and `tracert`
- Simulating user and group access
- Writing an onboarding/access support note

## Why This Matters

Entry-level IT support often starts with tickets like "the internet is not working" or "the new employee cannot access the shared folder." You do not need to be a network engineer to collect useful first evidence.
